Name pieces theme-role.png (e.g. stone-top_cap.png) — roles: 01, the four *_cap, center_vertical/horizontal, the *_trans corners/T-junctions, middle_trans. Bare names (middle_trans.png) join an “uploaded” theme. Missing pieces fall back; remembered in this browser.

Sprites

1.00×

Drop PNGs here or use the button — they spawn like the rest and are remembered in this browser. (Uploads are per-browser; for the built-in set on every device, add files to assets\sprites and rescan.)

Sliders scatter sprites randomly (clear of walls). For exact control: drag a sprite to move it, right-click (or select + Delete) to remove one, and hit place on a row then click the map to add that type anywhere — even types set to 0. Editing turns on “Keep on reroll” so your arrangement sticks; Export PNG saves it.
